跨场景共享
01 / ENTITY

实体识别

识别股票、产品、公司组织架构与员工名称，将自然语言中的名称或别名定位到统一实体。

股票 / 产品名称组织 / 员工名称别名与歧义消解
调用示意：名称或代码 → 候选实体与唯一标识；存在歧义时先确认。
02 / DATA ACCESS

数据接口（含权限控制）

为业务 MCP 提供统一的数据查询入口，适配上游数据库与接口，在执行查询时落实数据访问权限。

数据库 / 接口适配授权范围内查询来源与口径
调用示意：实体、指标、查询条件与用户上下文 → 获授权的数据及来源。
03 / AUTHORIZATION

用户角色与权限判断

识别用户身份、所属组织与业务角色，判断可调用工具和可访问数据范围，为数据接口提供授权依据。

身份 / 组织 / 角色工具与数据权限内部 / 外部隔离
调用示意：用户与目标资源 → 允许或拒绝、授权范围与判断原因。
04 / METRIC SEARCH

指标搜索

根据业务问题搜索匹配指标，定位指标名称、定义口径、适用维度及数据来源，支持后续准确取数。

指标检索定义 / 统计口径维度 / 数据来源
调用示意：业务关键词 → 候选指标及口径；确认指标后再调用数据接口。

以上为通用接口职责与调用设计，具体协议待实施确认。建议调用链：识别身份与权限 → 识别实体 / 搜索指标 → 按权查询 → 返回数据与来源。
